# Digital Footprints: Safety, Law & Ethics

A responsive, interactive educational website for a school assignment about location privacy in apps.

## Files
- `index.html` — page content, scenario, quiz, and source links
- `styles.css` — layout, colors, responsive styling, and accessibility states
- `script.js` — scenario feedback, checklist progress, quiz scoring, and reflection

## Run in VS Code
1. Download and unzip this project.
2. Open the `safety-law-ethics-website` folder in VS Code.
3. Open `index.html` and use **Open with Live Server** if you have the Live Server extension. Or open `index.html` directly in a browser.
4. Try every scenario choice, select all checklist items, submit the quiz with correct and incorrect answers, reset the quiz, and submit a reflection.
5. Make sure the three source links open.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `digital-footprints`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository's root (not just the ZIP file).
3. Open the repository's **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish and copy the public URL shown in Settings → Pages.
7. Open the public URL in a private/incognito window or another browser to verify that it works.

## Legal scope
The site summarizes Section 5 of the U.S. Federal Trade Commission Act for educational purposes. Whether conduct violates a law depends on the facts and applicable law; this site is not legal advice.
